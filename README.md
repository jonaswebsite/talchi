# TALCHI – Talk + Chat

Eine responsive Messenger-Website-Demo mit blau-türkisem Design.

## Starten
1. ZIP-Datei entpacken.
2. Den Ordner `talchi` öffnen.
3. `index.html` doppelklicken – die Website öffnet sich im Browser.

## Enthaltene Dateien
- `index.html` – Seitenstruktur
- `style.css` – Design und responsive Layout
- `script.js` – Chat-Demo und lokale Speicherung

## Hinweis
Dies ist zunächst ein Frontend-Prototyp. Nachrichten werden im Local Storage des Browsers gespeichert. Es gibt noch keinen echten Server, keine Benutzerkonten und keine funktionierenden Sprach-/Videoanrufe. Für einen echten Messenger benötigen wir später Backend, Datenbank, Authentifizierung und sichere Echtzeitkommunikation.
